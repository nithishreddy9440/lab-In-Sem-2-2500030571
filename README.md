# React Book Cards

A React + Vite project with a reusable `BookCard` component that receives `title` and `author` props and displays three books.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Push to GitHub

First sign in to the GitHub account that owns the destination repository, or ask that repository's owner to add your current account as a collaborator.

From this project folder, run:

```bash
git init
git add .
git commit -m "Initial React book cards project"
git branch -M main
git remote add origin https://github.com/chudamani2007/project.git
git push -u origin main
```

If `origin` already exists, update it instead of adding it:

```bash
git remote set-url origin https://github.com/chudamani2007/project.git
git push -u origin main
```

**Permission note:** A ZIP file cannot fix a GitHub `403 Permission denied` error. The GitHub account you authenticate as must have write access to `chudamani2007/project`. If GitHub authenticates you as `nithishreddy9440`, that account needs collaborator access, or you must sign in as `chudamani2007`.
